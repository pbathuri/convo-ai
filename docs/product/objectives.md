# North-star objectives

1. **Time-to-first-response:** Candidate reaches first spoken avatar response in < 90s; D-ID greeting p50 < 4s.
2. **Personas:** 5 role-specific personas live, versioned, measurable.
3. **Session artifact:** Every completed session → transcript + rubric score + 3 action items + history.
4. **KB traceability:** Every persona pins KB version; scoring returns retrieval trace.
5. **Operator console:** `/admin` manages personas, KB, scraper, sessions, scoring, cost.
6. **Guardrails:** Cost, consent, license, PII, data-quality gates before alpha.

## Acceptance (investor pilot)

- Demo: 60s session + score report for each persona
- Eval: rubric JSON validity > 99%; retrieval benchmark doc exists
- Governance: no KB chunk without `KbSource`; WRDS never in public UI
